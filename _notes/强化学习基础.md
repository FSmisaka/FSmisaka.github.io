# 强化学习问题与基本定义

[Refer](https://walkinglabs.github.io/hands-on-modern-rl/chapter03_mdp/bandit)

- Exploration 和 Exploitation

    exploitation：选择当前**动作奖励估计**最好的动作  
    exploration：探索不确定的动作

- e.g. 多臂老虎机

    **奖励期望** $\mathbb{E}[R_a] = \sum_{r}rP(R_a=r)$  
    选择动作 $a$ 后，每个奖励 $r$ 和得到该奖励的概率 $P(R_a=r)$

    **动作奖励估计** $\hat{\mu}_a=\frac{1}{N_a}\sum_{i=1}^{N_a}r_i$  
    过去 $N_a$ 次选择动作 $a$ 得到的平均奖励

    **$\epsilon$-greedy 策略** $a_t=\begin{cases} \arg\max_a \hat{\mu}_a &, \ 1-\epsilon \ 的概率 \\ 随机选择动作 &, \ \epsilon \ 的概率 \end{cases}$  
    这样能够平衡 explore 和 exploit

## 马尔可夫决策过程 Markov Decision Process

- **马尔可夫决策过程 MDP**  
    $\mathcal M = (\mathcal S, \mathcal A, \mathcal P, \mathcal R, \gamma)$  

    $\mathcal S$: 状态空间  
    $\mathcal A$: 动作空间  
    $\mathcal P$: 状态转移概率  
    $\mathcal R$: 奖励函数  
    $\gamma$: 折扣因子

    实际上还有另外一个重要参数：策略 $\pi$，决定了某个状态下会做的动作（或动作分布）

- **马尔可夫性**，即 无后效性  
    $P(S_{t+1} \mid S_t,A_t,S_{t-1},A_{t-1},\dots)=P(S_{t+1} \mid S_t,A_t)$
