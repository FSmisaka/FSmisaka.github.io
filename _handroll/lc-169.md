```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        hp = 0
        cur = None
        for num in nums:
            if hp == 0: cur, hp = num, 1
            elif cur == num: hp += 1
            else: hp -= 1
        return cur
```
